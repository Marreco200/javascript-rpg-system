# RPG XP System

## 📖 About

This project was created to practice basic JavaScript concepts such as variables, conditional statements, the ternary operator, and value manipulation.

## ⚙️ Features

- XP gain system
- Character classes (Mage, Warrior, and Archer)
- Class-based XP bonus
- Level-up system

## 🎯 Goal

The main goal of this project was to put into practice the JavaScript concepts I have been learning, without using any external libraries.

Through this simple RPG-inspired system, I practiced:

- `if` / `else` statements for decision making
- `let` and `const` for variable declaration
- The ternary operator for simple conditions
- Basic arithmetic operators to manipulate data

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
